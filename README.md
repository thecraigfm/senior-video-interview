# Video Interview GitHub Pages Site

This is a static, browser-only video interview practice site for MDPR 4130.

## Publish on GitHub Pages

1. Create a new GitHub repository, such as `video-interview`.
2. Upload `index.html`, `styles.css`, and `app.js` from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. After GitHub publishes the site, share the URL shown on that Pages settings screen.

GitHub Pages provides HTTPS, which browsers require for webcam and microphone access. Test the published link in the browsers your students are likely to use before assigning it.

## Privacy and student workflow

The site has no accounts and does not upload videos. Recordings live in the browser tab until the student downloads `video-interview.zip`. Refreshing or closing the tab before downloading discards recordings. The ZIP contains the ten responses and a `questions.txt` file.

Students should use a current desktop version of Chrome, Edge, Firefox, or Safari, permit camera and microphone access, and keep recordings under the five-minute maximum. A 5-minute answer is permitted but not required.
